# “현재 지역 전체” 선택 로직

현재 지역 전체 선택 기능을 구현한다


## 구현

- 현재 지역 전체 선택시 root 에서 관리되던 regionConditions에서 전체 지역 범위에 해당하는 지역이 이미 들어가 있었다면 삭제되어야한다

## 배경/의도
- “현재 지역 전체”는 **현재 선택된 시/군/구 전체를 조건으로 추가**하는 기능이다.
- 전체 조건은 하위(읍/면/동) 선택과 **상호 배타**로 동작해야 한다.

## 용어 정의
- **전체 조건(Whole Condition)**: `sigungu.code === eupmyeondong.code` 인 `SeletedRegionCondition` (현재 코드의 `isWholeRegionCondition` 기준을 그대로 사용)
- **하위 조건(Child Condition)**: 동일 시/군/구의 개별 읍/면/동 선택

## 동작 규칙 (필수)
1. **전체 선택 토글**
   - 동일 시/군/구의 전체 조건이 이미 있으면 제거, 없으면 추가.
2. **전체 선택 시 하위 조건 제거**
   - 동일 시/군/구에 속한 모든 읍/면/동 조건은 제거한다.
3. **하위 선택 시 전체 조건 제거**
   - 동일 시/군/구의 전체 조건이 존재하면 제거한 뒤 하위 조건을 토글한다.
4. **다른 시/군/구 조건은 유지**
   - 다른 시/군/구의 조건은 영향을 받지 않는다.

## UI/UX 요구사항
- “현재 지역 전체” 체크박스는 **선택 상태가 시각적으로 유지**되어야 한다.
- 하위 조건이 존재할 때 “전체”가 체크되면 하위 조건들이 즉시 해제되는 UI 피드백이 필요.
- 체크박스 클릭은 **중복 토글** 가능해야 한다(선택/해제).

## 데이터 생성 규칙
- 전체 조건 생성 시:
  - `sido`: 현재 선택된 시/도
  - `sigungu`: 현재 선택된 시/군/구
  - `eupmyeondong`: **sigungu와 동일한 code/name/displayName**
  - `id`: `sigungu.code` (또는 `sido.code + ':' + sigungu.code + ':ALL'` 형태로 충돌 방지 가능)
  - `displayName`: `시/도>시/군/구 전체`

## 고려 사항 / 미정의 영역
- “시/도 전체”까지 확장할지 여부(현재는 시/군/구 전체 기준으로 제한)
- `id` 설계(코드 충돌 방지 및 키 안정성)

## 수용 기준(AC)
- 동일 시/군/구의 하위 항목 여러 개가 선택된 상태에서 “현재 지역 전체”를 선택하면 하위 항목이 모두 사라지고 전체 조건만 남는다.
- 전체 조건이 있는 상태에서 하위 읍/면/동을 선택하면 전체 조건이 사라지고 하위 항목이 추가된다.
- “현재 지역 전체”를 다시 클릭하면 전체 조건이 제거된다.

## 테스트 시나리오
- 시/군/구 A의 읍/면/동 2개 선택 → 전체 선택 클릭 → 하위 2개 제거, 전체 1개 유지
- 시/군/구 A 전체 선택 → 읍/면/동 1개 선택 → 전체 제거, 하위 1개 유지
- 시/군/구 A 전체 선택 + 시/군/구 B 하위 선택 → 서로 영향 없음
